# Home Care category banner

The Home Care category has separate product-free desktop and mobile banners. Both use the bright blue and white laundry mood of the supplied reference, with folded linens, a wicker hamper, daisies, and natural light. The source artwork was generated with the built-in imagegen tool. Exact headline text was added with Sharp, then the final assets were saved in the repository:

- `public/assets/category/home-care-banner-2026-desktop.webp` (2000 × 600)
- `public/assets/category/home-care-banner-2026-mobile.webp` (1200 × 900)

Both final images were uploaded through the admin media API and assigned to the `Home Care` category banner record. The site's static banner fallback points to the same local assets. The banner lookup now prefers an exact, nonempty `Home Care` record before the legacy `Home` alias.
